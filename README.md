# 🎓 FairExam — Education Transparency Platform

FairExam is a data-driven web application designed to improve transparency and accountability in the Indian education system. It enables students to report exam-related issues and provides real-time analytics to identify patterns, trends, and systemic problems.

---

## 🚀 Features

* 📢 **Incident Reporting System**
  Students can report issues such as paper leaks, result discrepancies, server failures, and exam center problems.

* 📊 **Interactive Dashboard**
  Visualizes data using charts and metrics like:

  * Total reported issues
  * Most affected exams
  * Most common issue types

* 🚨 **Alert Detection System**
  Automatically identifies high-frequency issues and flags them as potential critical incidents.

* 📉 **Exam Trust Score**
  Calculates a trust metric for each exam based on the number of complaints reported.

* ⚡ **AI Sentiment Analysis**
  Uses NLP to classify student complaints into sentiment categories (Positive/Negative/Neutral).

* 📍 **Multi-Exam Support**
  Covers major Indian exams like NEET, JEE, UPSC, SSC, GATE, CAT, and more, with support for custom entries.

* 📄 **Live Incident Feed**
  Displays recent reports in a clean, real-time feed format.

---

## 🛠️ Tech Stack

* **Frontend & Backend**: Streamlit
* **Database**: SQLite
* **Data Processing**: Pandas
* **Visualization**: Altair
* **AI/NLP**: Hugging Face Transformers (Sentiment Analysis)

---

## 🧠 How It Works

1. Users submit exam-related issues via a form.
2. The system analyzes the complaint using an NLP model.
3. Data is stored in a structured database.
4. Dashboard updates dynamically with insights and visualizations.

## 🎯 Problem Statement

Students often face issues like:

FairExam provides a centralized platform to:
